# التطور چات — GitHub Ready

واجهة عربية RTL + Backend Express جاهز للربط مع OpenAI Responses API.

## تشغيل محلي
```bash
npm install
cp .env.example .env
# ضع OPENAI_API_KEY داخل .env
npm start
```

## Render
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable: `OPENAI_API_KEY`
- لا ترفع ملف `.env` إلى GitHub.
